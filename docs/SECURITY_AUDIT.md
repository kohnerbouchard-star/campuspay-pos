# Security scope

Restricted runtime database role, server-only pooled connection, allowlisted and parameterized RPC calls, signed-in role checks, masked PIN input, peppered PIN proofs and slow hashes, persistent account failure counters, 20-second cashier idle expiry, one-use reset authorization, and append-only journals.

This is not an independent security audit or production certification. Hardware behavior, recovery procedures, institutional privacy requirements, and deployment/network controls must be evaluated before handling real student funds.
